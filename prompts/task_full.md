Write the report with exactly these sections (### headings):

### 🎯 The 30-second summary
Exactly 3 numbered takeaways. Each one: a bold one-line finding, then one sentence on what it means for {{BRAND_NAME}}.

### ✅ Do this next
4-5 concrete actions for {{BRAND_NAME}}'s next 2 weeks, as a checklist ("- [ ] ..."). Each item: the action in bold, then why (one data point) and the expected effect (more reach, more replies, more saves...). Order by impact.

### 🔥 What works for them
The 3 strongest patterns. For each one: a #### heading with the pattern name, the best example post as a quote (with EN translation if needed) and its numbers in one line, then "**So what for {{BRAND_NAME}}:**" with one sentence.

### 📊 Topics and formats scorecard
A markdown table with columns: Topic or format | Posts | How it performs | Verdict. Verdict is one of 🟢 Do more, 🟡 Test, 🔴 Avoid. 5-8 rows, best first. One line after the table with the biggest surprise.

### 💬 What their audience wants
From comments and replies: the questions, pains and wishes people express, each with a short real quote. End with 2-3 content ideas that answer them. If comments were not collected, say so in one line and use the replies instead.

### 🚫 What to avoid
2-4 bullets: what gets views but no reactions, or what flopped, with one example each.

### ✍️ 5 ready-to-post drafts for {{BRAND_NAME}}
For each: a #### heading with the idea, then the full post in {{DRAFTS_LANGUAGE}} as a quote (with EN translation if not English), then one line: "**Why it should work:** ..." citing the pattern. Vary formats.

### 🪝 Hooks that worked
6-8 real first lines from their best posts. For each: the hook as a quote (with EN translation if not English) and its likes, then "→ **Template:**" a fill-in-the-blank version for {{BRAND_NAME}}. Best first.

### 🔤 Words and phrases to borrow
A markdown table with columns: Word or phrase | How they use it | Example | How {{BRAND_NAME}} can use it. 8-12 rows: emotional trigger words, recurring phrases, ways of addressing the reader, signature expressions. Keep the original language in the first column and add the English meaning in brackets if not English. After the table, one line: "**Avoid:**" 2-4 words or phrases that show up in their weak posts or clash with {{BRAND_NAME}}'s voice.

### 🗂️ Topic ideas
A markdown table with columns: Topic | Angle for {{BRAND_NAME}} | Based on | Priority. 8-10 rows. "Based on" names the competitor post, comment or gap that supports it. Priority is 🔥 High, ⭐ Medium or 💡 Try. Include at least 2 topics nobody covers yet.

### 🏷️ Tags to use
Threads lets you add one topic tag per post, and it decides which topic feeds the post can appear in. Based on the tags data and topics above: a markdown table with columns: Tag | Use it for | Why. 5-8 tags for {{BRAND_NAME}}, in the language of the audience. Mark tags the competitors use successfully with ✅ and new ones to try with 🧪. If no tag data was collected, suggest tags from the topics and say they are untested. One line after the table on hashtags in the text (use or skip, based on the data).

### 🧪 Hypotheses to test
3-5 hypotheses as a markdown table with columns: Hypothesis | How to test | What to measure | Success if. Write each hypothesis as "If {{BRAND_NAME}} ..., then ... because ...". Tests must be small: 4-6 posts over 2 weeks. Metrics: likes, replies, reposts, reactions per 100 views. "Success if" gives a clear threshold compared with {{BRAND_NAME}}'s usual posts.
